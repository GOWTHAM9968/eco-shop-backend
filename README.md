# 🌿 Eco Shop Management System

A modern offline Shop Management System built using HTML, CSS, JavaScript, Node.js, Express.js, MySQL, and XAMPP.

## 🚀 Features

### 🔐 Admin Panel
- Admin Login
- Secure Dashboard
- Sidebar Navigation
- Dark Mode Support

### 📦 Product Management
- Add Products
- Delete Products
- Product Images
- Search Products
- Stock Tracking

### 🧾 Billing System
- Add to Cart
- Quantity Selection
- Auto Total Calculation
- Print Bill
- Invoice Generation

### 📉 Stock Management
- Current Stock
- Auto Stock Reduction
- Low Stock Alerts
- Out of Stock Alerts

### 📊 Sales Dashboard
- Daily Sales
- Weekly Sales
- Monthly Sales
- Total Revenue

### 💸 Expense Management
- Rent Tracking
- Electricity Bills
- Salary Expenses
- Transport Expenses

### 🔁 Return Management
- Product Returns
- Return Reasons
- Loss Tracking

### 👥 Customer Management
- Add Customers
- Phone Numbers
- Addresses
- Customer Search

### 📜 Reports
- Sales Reports
- Expense Reports
- Profit & Loss Reports
- Stock Reports

## ⚙ Installation

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/EcoShop.git
```

### 2. Install Packages

```bash
cd backend
npm install
```

### 3. Start XAMPP

Start:
- Apache
- MySQL

### 4. Create Database

```sql
CREATE DATABASE eco_shop;
```

Import all required tables.

### 5. Run Backend

```bash
node server.js
```

### 6. Open Frontend

Use Live Server:

```text
http://127.0.0.1:5500/static/login.html
```
